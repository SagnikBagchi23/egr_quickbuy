# Intraday Order Card Prototype

Interactive HTML prototype exploring layout iterations for the intraday Buy order card, built with the Groww Mint Design System (dark mode).

## Iterations

| Tab | Description |
|-----|-------------|
| Existing | Stacked rows with divider lines and X dismiss buttons |
| I1 (Paired) | Side-by-side SL/TGT columns |
| I2 (Inline) | Stacked rows with inline X beside input |
| I3 (No Dismiss) | Stacked rows, SL/TGT always visible |
| I4 (Label X) | Stacked rows, X next to label, no dividers |

## Features

- Scroll-triggered appbar border
- Dismissable SL/TGT fields with smooth collapse animation
- Individual "+ SL" / "+ TGT" add-back CTAs
- Trailing stoploss option with configurable trail value
- Segmented tab switcher across iterations

## Usage

Open `index.html` in a browser.
